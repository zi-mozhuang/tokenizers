# 2026-09-19

## UAX #29 / ICU 句子预分词器设计方案
- 产出 `design/uax29-sentence-pretokenizer.md`：在 PreTokenizer 阶段做"段落（UAX #14 mandatory break）→ 句子（ICU4X SentenceSegmenter，UAX #29 SB 规则）"两级切分，段落仅作 barrier（管线是扁平 splits，无层级元数据）。
- 依赖选型：ICU4X `icu_segmenter`（纯 Rust，compiled_data，feature 门控 `icu`）；排除 rust_icu（FFI）；unicode-segmentation 为 fallback 备选。
- 核心实现仿 `UnicodeScripts`：`pretokenized.split()` + `Range::Normalized` 切片保证 offsets 无损；全局 `LazyLock<SentenceSegmenter>`。
- 新类型名 `UAX29Sentence`（参数 keep_separator/skip_empty）；注册点：PreTokenizerWrapper 四处（enum/EnumType/untagged/impl_enum_from!）。
- 环境注意：Windows 侧沙箱禁了 wsl.exe，UNC 路径（\\wsl.localhost\...）的 Read/Write/Glob/Grep 可用；Git Bash 里 ls 等基础命令缺失，避免用 Bash 工具做文件操作。

## 方案迭代 v1→v3（定稿）与用户决策
- v1 ICU4X 两级方案 → v2 正则组合+兜底 → **v3 定稿：单模块 SentenceSplit，unicode-segmentation 直切，零配置零新增依赖**。
- 用户决策链：①预分词必须无损（不增删改原文）②尽量复用现有 12 模块 ③允许兜底新模块 ④空白归属先选"并入后句"后**改为遵循 UAX #29 标准默认（SB11 并入前句）** ⑤**放弃段落划分**（UAX #29 无 paragraph 层级）⑥不用 Sequence，单节点模块。
